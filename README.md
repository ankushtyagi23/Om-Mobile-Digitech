# 📱 Om Mobile & Digitech — Official Store & Retail Platform

**Om Mobile & Digitech** is a full-featured, responsive retail web application built for an authorized smartphone sales, electronics accessories, and mobile repair center located in Umargam, Gujarat.

### 🌟 Key Features

- **📱 Smart Product Catalog & Filtering**: Browse original smartphones (Apple, Samsung, OnePlus, Xiaomi, Realme, Vivo), genuine chargers, audio gear, and protective accessories with price filters and real-time search.
- **🔐 Secure Multi-Mode Authentication**:
  - Standard Email & Password authentication.
  - **Instant OTP Authentication** for passwordless one-time passcode login.
  - **Self-Service Password Reset** with OTP verification flow.
- **🛒 Dynamic Cart & Multi-Step Checkout**:
  - Fully responsive, mobile-optimized cart drawer.
  - Doorstep delivery selection (Express 45-Min, Standard Same-Day, or In-Store Pickup).
  - Flexible payment options: UPI QR, Cards, and Cash on Delivery (COD).
- **📦 Order Tracking & Receipts**: Generates instant digital tax receipts and order IDs for store pickups and local delivery dispatches.
- **🛠️ Service Booking & Consultations**: Dedicated portal for device repairs, display replacements, battery servicing, and warranty inquiries.
- **📍 Store Location & Radar Navigator**: Interactive directions and landmark indicators for the physical counter in Umargam (`5QF8+7P Umargam`).
- **🛡️ Store Admin Management Desk**: Built-in admin portal for updating inventory, reviewing customer inquiries, and managing dispatch orders.

### 🛠️ Built With

- **React 18 & TypeScript**
- **Tailwind CSS** (High-contrast, neo-brutalist responsive styling)
- **Lucide Icons**
- **Vite**
